
**Formulas (Starting from Row 2):**

These formulas auto-populate based on the reference data and should be copied down for all transaction rows.

**Column A (TXN_ID):** 
```
=IF(A1="TXN_ID",A1,IF(COUNTA($A$2:A1)=0,1,MAX($A$2:A1)+1))
```

**Column K (ปีทุนที่ - Scholarship Year):**
Calculates which scholarship period this transaction falls into based on start/end dates from 02_Register.

**Column L (ปีงบประมาณ - Fiscal Year):**
Fiscal year runs Oct 1 - Sep 30. If month is Oct-Dec, year is +1.

**Column M (หมวดหมู่หลัก - Main Category):**
```
=IFERROR(VLOOKUP(E2,01_Config!$B$2:$A$43,2,FALSE),"")
```

**Column O (ประเภททุน - Scholarship Type):**
```
=IFERROR(VLOOKUP(B2,02_Register!$A:$C,3,FALSE),"")
```

## Step 3: Add Google Apps Script Automation

This script automatically validates input and inserts properly-formatted transactions into 04_Master_Data.

1. Go to **Extensions > Apps Script** in the Google Sheet
2. Delete the default code and paste this script:

```javascript
function validateAndInsertExpense() {
  const sheet = SpreadsheetApp.getActive();
  const inputSheet = sheet.getSheetByName('04_Input');
  const masterSheet = sheet.getSheetByName('04_Master_Data');
  const configSheet = sheet.getSheetByName('01_Config');
  const registerSheet = sheet.getSheetByName('02_Register');
  
  // Get input data from row 2 (adjust if using different row)
  const inputRange = inputSheet.getRange('A2:I2');
  const inputValues = inputRange.getValues()[0];
  
  const scholarCode = inputValues[0];      // A: รหัสผู้รับทุน
  const sequence = inputValues[1];         // B: ลำดับที่
  const paymentDate = inputValues[2];      // C: วันที่เบิกจ่าย
  const item = inputValues[3];             // D: รายการ
  const amount = inputValues[4];           // E: จำนวน
  const currency = inputValues[5];         // F: สกุลเงิน
  const paymentMethod = inputValues[6];    // G: วิธีการจ่าย
  const status = inputValues[7];           // H: สถานะ
  const notes = inputValues[8];            // I: หมายเหตุ
  
  // Validate required fields
  if (!scholarCode || !sequence || !paymentDate || !item || amount === '' || !status) {
    SpreadsheetApp.getUi().alert('⚠️ Please fill all required fields (★)');
    return;
  }
  
  // Validate Scholar Code exists in 02_Register
  const registerData = registerSheet.getRange('A2:A' + registerSheet.getLastRow()).getValues();
  const scholarExists = registerData.some(row => row[0] === scholarCode);
  if (!scholarExists) {
    SpreadsheetApp.getUi().alert('⚠️ Scholar Code not found: ' + scholarCode);
    return;
  }
  
  // Validate Item exists in 01_Config
  const configData = configSheet.getRange('B2:B' + configSheet.getLastRow()).getValues();
  const itemExists = configData.some(row => row[0] === item);
  if (!itemExists) {
    SpreadsheetApp.getUi().alert('⚠️ Item not found: ' + item);
    return;
  }
  
  // Insert into 04_Master_Data
  const masterLastRow = masterSheet.getLastRow();
  const newRow = masterLastRow + 1;
  
  // Build row with formulas for auto-calculated columns
  const newData = [
    '', // A: TXN_ID (auto-calculated by formula)
    scholarCode,
    sequence,
    paymentDate,
    item,
    amount,
    currency || '',
    paymentMethod || '',
    status,
    notes || ''
  ];
  
  // Insert the row
  masterSheet.insertRows(newRow, 1);
  masterSheet.getRange(newRow, 1, 1, newData.length).setValues([newData]);
  
  // Clear input form
  inputSheet.getRange('A2:I2').clearContent();
  
  SpreadsheetApp.getUi().alert('✓ Data inserted successfully! Row ' + newRow + ' in 04_Master_Data');
}

function onOpen() {
  const ui = SpreadsheetApp.getUi();
  ui.createMenu('Submit')
    .addItem('Submit Expense', 'validateAndInsertExpense')
    .addToUi();
}
```

3. Save the script (Ctrl+S or Cmd+S)
4. Go back to the Google Sheet and refresh it
5. You'll see a new "Submit" menu at the top of the sheet

## Step 4: Set Up Data Validation

In Sheet 04_Input, set up dropdown menus:

**Column A (Scholar Code):**
1. Select range A2:A101
2. Go to **Data > Data validation**
3. Choose "List from a range"
4. Range: `02_Register!A:A`
5. Check "Show dropdown arrow"

**Column D (Item):**
1. Select range D2:D101
2. Data validation > List from a range
3. Range: `01_Config!B:B`

**Column H (Status):**
1. Select range H2:H101
2. Data validation > List from a range
3. Range: `01_Config!E:E` (สถานะการเบิกจ่าย column)

**Column F (Currency):**
1. Select range F2:F101
2. Data validation > List from a range
3. Range: `01_Config!F:F`

## How to Use

1. **Enter expense data** in Sheet 04_Input:
   - Fill in Scholar Code, Sequence, Payment Date, Item, Amount, Status
   - Other fields are optional

2. **Click "Submit" menu** > "Submit Expense"

3. **Validation runs automatically**:
   - Checks that Scholar Code exists
   - Checks that Item exists
   - Checks all required fields are filled

4. **Data inserts into 04_Master_Data**:
   - Auto-calculated fields (ปีทุนที่, ปีงบประมาณ, Category, etc.) populate via formulas
   - TXN_ID auto-increments
   - Form clears for next entry

5. **Dashboard updates automatically**:
   - All charts and summaries recalculate
